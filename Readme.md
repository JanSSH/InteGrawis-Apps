# Cara Menggunakan InteGrawis

## 1. Download InteGrawis.apk

Buka halaman download InteGrawis, kemudian pilih **Download** untuk mengunduh file `InteGrawis.apk`.

![Download InteGrawis APK](https://github.com/user-attachments/assets/9294a04e-b9fd-4255-9234-d121e3f64b84)

---

## 2. Install Aplikasi

Setelah file APK selesai diunduh:

1. Buka file `InteGrawis.apk`.
2. Jika muncul peringatan keamanan, pilih **Settings / Pengaturan**.
3. Izinkan instalasi aplikasi dari **sumber tidak dikenal / pihak ketiga**.
4. Kembali ke proses instalasi.
5. Tekan **Install**.
6. Tunggu hingga proses instalasi selesai.

![Instalasi InteGrawis](https://github.com/user-attachments/assets/2b5c3228-7951-41b3-a9a8-67895fe15797)

> **Catatan:** Opsi "Install unknown apps" dapat memiliki nama atau lokasi menu yang berbeda tergantung versi Android dan perangkat yang digunakan.

---

## 3. Login

Setelah aplikasi berhasil terpasang, buka **InteGrawis**.

Masukkan akun sesuai dengan **user yang telah diberikan**.

![Login InteGrawis](https://github.com/user-attachments/assets/bb82692c-03bb-4dd9-87fe-b844d8e0db61)

Pastikan username dan password yang dimasukkan sudah benar sebelum menekan tombol **Login**.

---

## 4. Aplikasi Siap Digunakan

Setelah berhasil login, pengguna akan masuk ke halaman utama InteGrawis.

Aplikasi sudah siap digunakan untuk melakukan **presensi**.

![Halaman Utama InteGrawis](https://github.com/user-attachments/assets/c3846a9a-617a-4b85-b8bd-4a0c05561194)

#  Persyaratan

Sebelum menggunakan InteGrawis, pastikan:

* Perangkat menggunakan **Android**.
* Perangkat tersambung wifi Grawis.
* Pengguna memiliki akun InteGrawis yang valid.
* Instalasi aplikasi dari sumber pihak ketiga diizinkan pada perangkat.
